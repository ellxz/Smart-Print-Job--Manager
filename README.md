# Smart Print Job Manager

## Project Description
The Smart Print Job Manager is a C++ console application
that demonstrates how queues are used to manage print jobs.

It follows the First In, First Out (FIFO) principle,
where the first document added is the first document processed.

## Features
- Add print jobs
- Process the next document
- View pending print jobs
- Exit the application

## Data Structure
This project uses the queue data structure provided
by the C++ Standard Template Library (STL).

## Technologies Used
- C++
- C++ Standard Template Library (STL)

## How to Run

1. Compile the program:

g++ print_manager.cpp -o print_manager

2. Run the program on Windows:

.\print_manager.exe
